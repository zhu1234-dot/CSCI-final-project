# CSCI-final-project
block letter generator in C++
This C++ program reads character symbols and their coordinates from an input text file and displays block letters in the console. 

## Files 
M08_InputData.cpp - C++ source code 
M08_InputData_CPP.txt - Input data 

## How to run 
Compile: 
clang++ -std=c++14 M08_InputData.cpp -o project
Run: 
./project 

## Error Handling 
The program displays error messages if the input file is missing, empty, or contains negative coordinates.
